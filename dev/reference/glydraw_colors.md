# Default color palette in glydraw

This palette uses the SNFG standard defined in
https://www.ncbi.nlm.nih.gov/glycans/snfg.html.

## Usage

``` r
glydraw_colors()
```

## Value

A named character vector of colors.

## Examples

``` r
glydraw_colors()
#>     glyWhite      glyBlue     glyGreen    glyYellow    glyOrange      glyPink 
#>    "#FFFFFF"    "#0072BC"    "#00A651"    "#FFD400"    "#F47920"    "#F69EA1" 
#>    glyPurple glyLightBlue     glyBrown       glyRed 
#>    "#A54399"    "#8FCCE9"    "#A17A4D"    "#ED1C24" 
```
